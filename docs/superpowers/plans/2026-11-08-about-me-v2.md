# Окно «Обо мне» v2 (страница-профиль) — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** «Обо мне» открывается сразу страницей-профилем (текст, опыт, образование) со сворачиваемыми карточками «Соцсети / Навыки / Стек технологий», кнопками «Мои проекты» и «Моё резюме» и строкой состояния.

**Architecture:** Меняются только файлы окна `Open_Windows/About Me/*` и тесты; рамка, механизм `openWindow`, иконка, тестовый стенд остаются. `about-me.js` переходит с плиток на «страницы» `profile` и `projects` с той же историей `win._am`. Сворачивание карточек — CSS (`grid-template-rows: 1fr→0fr` + `rotate(180deg)`), JS только переключает класс.

**Tech Stack:** HTML/CSS/JS без сборки; тесты `node:test` + `puppeteer-core` (`npm test`).

**Spec:** `docs/superpowers/specs/2026-11-08-about-me-v2-design.md`

## Global Constraints

- Всё на русском. Тексты UI: «Обо мне», «Соцсети», «Навыки», «Стек технологий», «Опыт работы», «Образование», «Мои проекты», «Моё резюме», «Назад», «Вперёд», «Готово», «Файл резюме пока не добавлен».
- Меню: «Файл», «Вид», «Справка» (файлы `Tooltip/File.html`, `View.html`, `Help.html` уже есть).
- Адрес: «Обо мне» на профиле, «Обо мне › Мои проекты» на проектах.
- Анимация: только CSS, длительность 250 мс, при `prefers-reduced-motion: reduce` — без анимации. Библиотек не добавлять.
- Резюме: `/Assets/Docs/resume.pdf`; кнопка «Моё резюме» — `<a target="_blank">`, когда файл есть; иначе страница с сообщением.
- Контент только из `about-me-data.js`; заглушки помечены `[заполните]`; текст вставляется через `textContent`.
- Пути иконок XP: `/Assets/Windows XP High Resolution Icon Pack avec MAOSX/Windows XP High Resolution Icon Pack/Windows XP Icons/<Name>.png`.
- Без git-коммитов (решение владельца).

## Review Focus

- Карточка свёрнута, затем окно закрыто и открыто снова — все карточки снова развёрнуты (тест в Task 2).
- Быстрый двойной клик по заголовку карточки — итоговое состояние совпадает с числом кликов, стрелка и содержимое согласованы (тест в Task 2).
- Свёрнутая карточка не принимает фокус/клики по скрытым ссылкам (тест в Task 2: у скрытых ссылок `tabIndex = -1` или `inert`).
- Абзац без картинки — текст на всю ширину, без пустого места слева (тест в Task 1).
- Очень длинный профиль — прокрутка внутри области, строка состояния и шапка видны (тест в Task 1).
