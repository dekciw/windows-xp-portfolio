# Окно «Обо мне» v2 — страница-профиль

Дата: 2026-11-08 · Статус: на согласовании · Заменяет главную с плитками из
`2026-11-08-about-me-window-design.md` (рамка, шапка, тесты, иконка остаются).

## Зачем

Работодатель или гость открывает «Обо мне» и сразу видит, кто вы, ваши навыки, стек и
соцсети — без лишних кликов. Ориентир — присланный скриншот (окно «About Me» в стиле XP):
карточки слева, крупный заголовок и текст справа. Свой контент, всё на русском.

## Что видит посетитель

```
┌ Обо мне ─────────────────────────────────────────── _ □ X ┐
│ Файл  Вид  Справка                                     ⊞ │
│ ◀ Назад  ▶ Вперёд │ 🌐 Мои проекты  📄 Моё резюме │ 📁    │
│ Адрес [Обо мне                                    ▾] → │
│┌──────────────┐│  Обо мне                             ▲│
││ Соцсети    ⌃ ││  [картинка]  Абзац 1 …               ││
││ • Telegram   ││  [картинка]  Абзац 2 …               ││
│├──────────────┤│  Опыт работы                         ││
││ Навыки     ⌃ ││   Должность · Компания · годы        ││
│├──────────────┤│  Образование                         ││
││ Стек       ⌃ ││   …                                  ▼│
│└──────────────┘│                                       │
│ Готово                                                  │
└─────────────────────────────────────────────────────────┘
```

- Открывается сразу страница «Обо мне» (плиток больше нет).
- **Боковая панель:** три карточки — «Соцсети» (primary, синий заголовок), «Навыки»,
  «Стек технологий». Каждая строка — иконка 16px + текст; в «Соцсетях» строки — ссылки
  (новая вкладка, `mailto:` — без новой вкладки).
- **Сворачивание:** клик по заголовку карточки (или стрелке) — содержимое плавно
  сворачивается/разворачивается, стрелка плавно поворачивается на 180°. Только CSS
  (`transition`), без библиотек. Анимация ~250 мс; уважать `prefers-reduced-motion`.
- **Основная область:** заголовок «Обо мне» (Trebuchet MS Bold, белый), абзацы белым
  Tahoma ~15px с лёгкой тенью; у абзаца необязательная картинка слева (~80px). Ниже —
  разделы «Опыт работы» и «Образование» (заголовок + записи). Прокрутка внутри области.
  Бледная иконка «Панели управления» в углу остаётся.
- **Панель кнопок:** «Назад», «Вперёд» | «Мои проекты» (IE), «Моё резюме» (PDF) | папка
  (вверх, на страницу «Обо мне»).
  - «Мои проекты» открывает страницу проектов внутри окна; «Назад/Вперёд» работают.
  - «Моё резюме» — настоящая ссылка на `/Assets/Docs/resume.pdf`, если файл есть;
    иначе страница с сообщением «Файл резюме пока не добавлен» (как сейчас).
- **Меню:** Файл, Вид, Справка (как на скриншоте); Файл → Закрыть работает.
- **Строка состояния** внизу: «Готово».
- Адрес: «Обо мне» / «Обо мне › Мои проекты».

## Не цели

- Перенос чужого контента или картинок со скриншота.
- Отдельные окна для проектов/резюме; бэкенд.

## Подходы

- **A — сразу страница-профиль (выбран, по запросу «при открытии выглядело так»).**
- B — плитки как стартовый экран + страница в новом стиле. Лишний клик; отклонён.
- Анимация: **CSS** (выбрано владельцем) vs Motion (vanilla) — библиотека не нужна для двух
  переходов.

## Контент

Весь контент — в `about-me-data.js`: `social[]` ({label, icon|iconSrc, href}), `skills[]`,
`stack[]` ({label, icon|iconSrc}), `about[]` ({text, image?}), `experience[]`,
`education[]`, `projects[]`, `resume`. Пока владелец не прислал данные — заглушки
`[заполните]`; иконки соцсетей — из проекта (GitHub, LinkedIn, Email) до получения своих.

## На усмотрение исполнителя

- Иконки навыков/стека по умолчанию — подходящие XP-иконки из проекта.
- Точные размеры шрифтов/отступов — по скриншоту, в пределах стиля проекта.
- Тесты главной с плитками заменяются тестами страницы-профиля; навигация, резюме,
  закрыть/открыть, узкое окно, иконки рабочего стола — сохраняются.
