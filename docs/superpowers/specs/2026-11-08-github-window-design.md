# Окно «GitHub» вместо «LinkedIn» — дизайн

Дата: 2026-11-08 · Статус: на согласовании

## Зачем

При запуске рабочего стола в панели задач появляется окно «LinkedIn» со скриншотом профиля
чужого человека (автора исходного проекта). Нужно показывать свой GitHub — живыми данными.

## Что видит посетитель

```
┌ GitHub — Microsoft Internet Explorer ───────────────── _ □ X ┐
│ File Edit View Favorites Tools Help                          │
│ ◀ Back ▶ … (панель IE как сейчас)                            │
│ Address [https://github.com/dekciw                 ] → Go    │
│┌───────────────┬───────────────────────────────────────────┐│
││  (аватар)     │ Репозитории  10                           ││
││  dekciw       │ ┌ windows-xp-portfolio ┐ ┌ promet-lokers ┐ ││
││  «Фронтенд —  │ │ описание…            │ │ описание…     │ ││
││   место, где…»│ │ ● C++  ☆1  обновлён… │ │ ● JS ☆1 …     │ ││
││  📍 Moscow    │ └──────────────────────┘ └───────────────┘ ││
││  0 подписч.   │  … (все репозитории, по дате обновления)  ││
││ [Открыть на   │                                           ││
││   GitHub]     │                                           ││
│└───────────────┴───────────────────────────────────────────┘│
│ Done                                          Internet       │
└──────────────────────────────────────────────────────────────┘
```

- Окно называется «GitHub» (заголовок, панель задач, иконка GitHub). Как и раньше, при
  загрузке рабочего стола открывается **свёрнутым** в панели задач.
- Рамка — тот же Internet Explorer, что у окна LinkedIn; адрес `https://github.com/dekciw`
  (ссылка, новая вкладка).
- Страница внутри — белая, в духе профиля GitHub: слева аватар, логин (имя, если задано),
  описание, город, подписчики/подписки, кнопка «Открыть на GitHub»; справа «Репозитории N» —
  карточки 2 в ряд (1 в узком окне): название-ссылка, описание, язык с цветной точкой, звёзды,
  «обновлён <дата>». Сортировка — по дате обновления. Форки и служебный репозиторий
  профиля (`dekciw/dekciw`) не показываются.
- Пока данные грузятся — «Загрузка…» в стиле XP. Если GitHub недоступен или лимит
  исчерпан — XP-сообщение «Не удалось загрузить профиль GitHub» и ссылка на github.com/dekciw.

## Как устроено

- Данные — `GET https://api.github.com/users/dekciw` и `/users/dekciw/repos?sort=updated&per_page=100`
  из браузера (CORS разрешён, без ключей). Логин — константа в одном месте.
- Кэш ответа в `localStorage` на 1 час (обёрнут в try/catch; без него — просто запрос).
- Весь текст вставляется через `textContent`.
- Новое окно `Open_Windows/GitHub/` (HTML/CSS + `github.js`), по схеме остальных окон;
  `Bureau.js` при старте открывает `GitHub` вместо `LinkedIn`; иконка `GitHub.png` в пакете
  иконок (из `github-logo.svg`).
- Удаляются: окно `Open_Windows/LinkedIn/`, `Assets/Images/Profiles/linkedin-profile.png` и
  `Assets/Images/Profiles/github-profile.png` (скриншоты чужих профилей).

## Не цели

- Закреплённые (pinned) репозитории и график активности — их нет в открытом API без ключа.
- Сервер/бэкенд.

## Подходы

- **B — живая карточка через GitHub API (выбран владельцем).**
- A — скриншот страницы GitHub: точный вид, но устаревает; отклонён.

## Проверка

E2E-тесты с подменой ответов GitHub (детерминированно): старт → окно «GitHub» свёрнуто;
профиль и репозитории отрисованы, форки и `dekciw/dekciw` скрыты; загрузка; ошибка/лимит;
кэш (второй открытие без запроса); ссылки в новой вкладке; узкое окно — 1 колонка.
