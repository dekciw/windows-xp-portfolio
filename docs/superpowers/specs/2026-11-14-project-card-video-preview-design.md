# Видео-превью карточки проекта — дизайн

**Дата:** 2026-11-14 · **Размер:** небольшая правка (одна карточка, потом масштабируем на 13)

## Зачем
В «Моих проектах» карточка в покое показывает обложку, а при наведении — видео проекта с дорожкой прогресса (как превью на YouTube / референс MyProjects). Первая карточка — Burger Cheddar; остальные 12 проектов подключатся позже теми же полями данных.

## Цели
- Обложка (cover) в покое; видео не загружается до первого наведения.
- Наведение или фокус с клавиатуры: видео с начала, без звука, по кругу, пока курсор/фокус на карточке.
- Обложка скрывается только когда видео реально пошло (событие `playing`) — без чёрного кадра.
- Красная дорожка #FF0000 высотой 3px внизу превью, ширина = currentTime / duration; видна только во время проигрывания.
- Уход курсора/фокуса: пауза, сброс на 0, дорожка 0, снова обложка.

## Не-цели
Телефоны (нет наведения), звук, управление видео, остальные 12 проектов.

## Анти-цели
Чёрный кадр при наведении; загрузка видео при открытии окна; поломка карточек без видео (заглушка «Скоро здесь будет превью» и картинка `thumb` работают как раньше).

## Подходы
1. **`<video>` внутри `.mp-thumb` поверх обложки** — выбрано: браузер сам играет и зацикливает, дорожка — по времени видео.
2. GIF / анимированный WebP — в 5–10 раз тяжелее, дорожка невозможна.
3. Свой плеер/библиотека — избыточно для беззвучного превью.

## Решения
- Файлы: `Assets/Projects/covers/BurgerCheddar.jpg` (1280×720, 137 КБ), `Assets/Projects/previews/BurgerCheddar.mp4` (H.264 1280×720, 8 с, 715 КБ) — копии из `C:\Users\atanov.r\Project\projects\presentations\`, без пережатия.
- Данные: карточка «Калькулятор локеров» заменяется на `{ title: "Burger Cheddar", category: "personal", views/date — демо, thumb: cover, video: preview, href: "" }`. Новое поле `video`.
- Разметка карточки с `video`: `.mp-thumb > img` (обложка) + `video.mp-thumb-video` (muted, loop, playsinline, preload="none", src ставится при первом наведении) + `.mp-progress > .mp-progress-bar`.
- Состояние «играет» — класс `is-playing` на `.mp-thumb`.
- Версия скриптов в `Bureau.html` поднимается (`my-projects-data.js`, `my-projects.js`).
