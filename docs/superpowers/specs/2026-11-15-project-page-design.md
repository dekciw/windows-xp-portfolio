# Страница проекта в «Моих проектах» — дизайн

**Дата:** 2026-11-15 · **Размер:** проект

## Зачем
Щелчок по карточке в окне «Мои проекты» открывает страницу проекта в том же окне — как видео на YouTube: плеер-карусель с медиа проекта, название, описание, комментарии. Пользователь хочет точную копию референса (4 скриншота страницы Handbook Studio Website) и макета Figma (`725:8293` — окно 848px, `733:9938` — развёрнутое 1280px), но со своим содержимым. Первый проект — Burger Cheddar; остальные подключатся позже теми же полями данных.

## Референсы
- Скриншоты страницы-референса: `docs/superpowers/specs/assets/2026-11-15-project-page/ref-1-player.png` (плеер), `ref-2-info.png` (название, точки, описание), `ref-3-desc-comments.png` (описание развёрнуто, «Show less», шапка комментариев), `ref-4-comments.png` (список комментариев).
- Figma: файл `bHVQ06w1nLYw5y2nob0Sdm` («Промет Калькулятор Локеров»), узлы `725:8293` (окно 848px) и `733:9938` (развёрнутое 1280px). Захват html.to.design — местами пустые слои; числа ниже сняты из него.

## Раскладка (из Figma)
- Шапка и боковое меню — существующие (как в сетке); боковое меню остаётся видимым на странице проекта (узкое окно — значки 72px, широкое — 160px с подписями, как сейчас).
- Колонка контента (`div.video-content`) — одна, без правой колонки: начинается на 16px правее линии бокового меню, сверху 17px от шапки, справа 16px; ширина = вся доступная (727.33 при окне 848; 1071.33 при 1280). Плеер, блок информации и комментарии — во всю ширину колонки.

## Цели
1. Щелчок по карточке (или Enter/Пробел) → страница проекта в том же окне; адрес `https://www.myprojects.com/<slug>` (Burger Cheddar → `burger-cheddar`); строка состояния справа — название проекта.
2. Кнопки панели «Назад»/«Вперёд» работают как в браузере (сетка ↔ проект); активны только когда есть куда идти. «Домой», логотип, пункты бокового меню и поиск возвращают к сетке.
3. **Плеер-карусель** (`div.video-player`): чёрный фон, скругление 12px, белая рамка 1px поверх, высота по пропорции 16:9 ширины (макет: 727.33×314.53 в узком окне — там медиа letterbox на чёрном; используем 16:9 контейнер, медиа `object-fit: contain` на чёрном).
   - Слайды: первый — видео-презентация, далее скриншоты.
   - Стрелки `‹` `›` по бокам: зона 88×44 по вертикальному центру, иконка 45.59px, opacity 0.4, `drop-shadow(0 0 8px rgba(0,0,0,.35)) drop-shadow(0 1px 2px rgba(0,0,0,.7))`; при наведении opacity 1. Скрыты, если слайд один. По кругу (с последнего на первый).
   - Точки под плеером справа от названия: 14px, gap 8px; активная — заливка и рамка 2px `red`; остальные — рамка 2px `#aaa`; щелчок — к слайду.
   - Смена слайда — сдвиг ленты `transform: translateX`, переход 0.3s; видео при уходе со слайда — пауза.
4. **Слайд-видео** (референс скриншот 1):
   - До запуска: постер, затемнение сверху (градиент), название проекта белым 24px слева сверху, большая красная кнопка ▶ по центру (68×48, скругление 14px, `#f00`, белый треугольник).
   - Управление снизу (видно при наведении на плеер и на паузе; скрывается через 2.5 с без движения мыши во время проигрывания): дорожка во всю ширину с отступами 16px — фон `rgba(255,255,255,.4)`, проиграно `#f00`, буфер `rgba(255,255,255,.6)`, ползунок-круг 13px `#f00` (виден при наведении на дорожку); перемотка щелчком и перетаскиванием. Ниже ряд: кнопка Play/Pause (круг 56px с пунктирной обводкой фокуса как в референсе — обводка только при фокусе с клавиатуры), время `0:07 / 0:14` (Roboto 16px белый), справа ссылка «↗ Открыть сайт» (Roboto Medium 16px, иконка 20px, новая вкладка) и кнопка полноэкранного режима (иконка 24px).
   - Звук включён (это полная презентация); клавиши: Пробел/K — пауза, ←/→ — ±5 с, F — полный экран (когда фокус внутри плеера).
   - Конец видео — снова постер с кнопкой ▶ (без автоперехода к следующему слайду).
5. **Слайд-картинка**: изображение `object-fit: contain` на чёрном; при наведении снизу градиент `rgba(0,0,0,0)→rgba(0,0,0,.78)` высотой 88px и круглая кнопка полноэкранного режима 40px (`rgba(0,0,0,.3)`, скругление 28px, иконка 24px) справа.
6. **Полноэкранный режим** — Fullscreen API на элементе плеера (видео и картинка заполняют экран, стрелки и управление остаются); Esc выходит.
7. **Блок под плеером** (`video-info-section`, отступы сверху 12px, снизу 28px, gap 12px):
   - Ряд meta (gap 28px): аватар 40px круглый + название Roboto Bold 26px / 29.9px / −0.5px белый + строка `views • ago` Roboto 14px / 16.8px `#aaa` (те же функции `viewsLabel`/`timeAgo`, что в карточках); справа точки; в широком окне (≥ 1000px ширины контента) — метки-категории: первая красная (`#c00`, рамка `#c00`), остальные серые (`#1e1e1e`, рамка `#333`), Roboto Medium 14px, межбуквенный 0.3px, отступы 7.67/15.67/8.33px, скругление 20px. Узкое окно — метки скрыты (как макет 725:8293).
   - **Описание** (`video-description`): фон `#1e1e1e`, рамка 1px `#333`, скругление 12px, отступы 11.67px; строки gap 16px, разделитель снизу 0.667px `#333` (кроме последней); подпись 108px шириной, Roboto Medium 16px `#aaa`; содержимое Roboto 16px / 24px белый. Строки по порядку: «Задача:», «Роль:», «Описание:». Свёрнуто — «Задача» и «Роль» целиком, «Описание» обрезано до 3 строк (`line-clamp: 3`) и кнопка «Ещё»; развёрнуто — всё и «Свернуть» (Roboto Medium 14px `#aaa`, снизу слева, как `ref-3`). Если «Описание» помещается в 3 строки — кнопки нет. По умолчанию свёрнуто.
8. **Комментарии** (`comments-section`, отступы 0 16px 16px, gap 20px):
   - Шапка: «N комментариев» (склонение; Roboto Bold 16px) и через 32px кнопка «Сортировка» (иконка 16px + текст 14px `#aaa`) — переключает «сначала новые/сначала популярные».
   - Добавление: аватар-силуэт 32px, поле «Добавьте комментарий…» (нижняя граница 0.667px `#333`, растёт до 120px), кнопка «Отправить» (32px высотой, скругление 20px; пустое поле — серая `#272727` неактивная, с текстом — `#f00`). Enter (без Shift) отправляет.
   - Список (pt 12px, gap 24px): аватар 32px; `@имя` Roboto Medium 13px белый + ` • 1 день назад` 12px `#aaa`; текст 14px / 20px; ряд 👍 N 👎 N (иконки 20px, gap 16px) — щелчок ставит/снимает реакцию.
   - Свой комментарий и реакции сохраняются в `localStorage` (ключ по slug проекта) и видны только этому посетителю; имя — «@гость».
9. Тема светлая/тёмная — все новые цвета через `--mp-*` (светлые значения по аналогии с текущей светлой темой).

## Не-цели
Настоящие общие комментарии (сервер), модерация, «Открыть в просмотрщике» (на сайте нет просмотрщика), автопереход слайдов, качество видео/субтитры/скорость, страницы остальных 12 проектов.

## Анти-цели
- Тяжёлая загрузка: видео 22 МБ не грузится при открытии окна — только при открытии страницы проекта и с `preload="metadata"`.
- Придуманные отзывы от «реальных людей»: комментарии в данных пустые, пока пользователь не вставит настоящие.
- Поломка сетки: поиск, категории, тема, видео-превью карточек работают как раньше.

## Подходы
1. **Второе состояние того же окна** (выбрано): `my-projects.js` получает режим `view: "grid" | "project"` и историю; шапка/меню/тема общие.
2. Отдельная HTML-страница в iframe — раздвоение шапки, темы, навигации.
3. Отдельное окно XP на проект — не как на референсе.

## Данные (`my-projects-data.js`, поля проекта)
- `slug` — `"burger-cheddar"`.
- `tags` — метки страницы: `["Личные", "Сборки"]` (первая красная).
- `media` — слайды: `{ type: "video", src, poster }` | `{ type: "image", src, alt }`.
- `site` — ссылка «Открыть сайт»: `https://dekciw.github.io/BurgerCheddar/`.
- `brief`, `role` — пока заглушки `"[заполните] Задача проекта"` / `"[заполните] Ваша роль в проекте"` (пользователь впишет сам); `desc` — по фактам README Burger Cheddar, по-русски: «Тёмная тема с огнём, меню с якорями и плавной прокруткой. В меню 12 бургеров с составом, весом и ценой; цена пересчитывается в $, ₽, BYN, € и ¥ при смене валюты в шапке. Форма заказа подсвечивает пустые поля, показывает сообщение после заказа и сама очищается; заказ не отправляется на сервер. Свой шрифт, чистые HTML, CSS и JavaScript, сайт опубликован на GitHub Pages.»
- `comments` — `[{ user, date, text, likes, dislikes }]`, для Burger Cheddar — `[]`.
