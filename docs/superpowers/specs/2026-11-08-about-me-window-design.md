# Окно «Обо мне» — дизайн

Дата: 2026-11-08 · Статус: на согласовании

## Зачем

Портфолио смотрят работодатели и просто любопытные люди. Цель — чтобы о владельце было
интересно узнавать «по-XP-шному». Окно «Обо мне» — главная точка входа в резюме: иконка на
рабочем столе, окно в стиле «Панели управления» (Figma: Windows XP UI Kit, node `2202:3735`).

## Цели

- Иконка «Обо мне» на рабочем столе; двойной клик открывает окно.
- Окно выглядит родным для проекта: та же рамка/кнопки (`Open_Windows/Base`), то же меню,
  панель кнопок и адресная строка, что у «Мой компьютер» (те же классы и стили), Tahoma 11px.
- Тело окна — по макету: голубая боковая панель слева, синяя область справа с заголовком
  (Trebuchet MS Bold 30px, белый 66%), плитки-категории (иконка 48px + Tahoma Bold 11px белым),
  бледная крупная иконка-водяной знак в правом нижнем углу.
- Подход **A** (выбран): клик по плитке открывает страницу раздела внутри того же окна.
  «Назад»/«Вперёд» работают, «Вверх» возвращает к плиткам, адресная строка показывает
  `Обо мне › <раздел>`.

## Не цели

- Бэкенд, загрузка контента с сервера, админка.
- Перерисовка рамки окна по Figma — используется рамка проекта (как у всех окон).
- Замена данных прежнего автора в других окнах (LinkedIn, «Мой компьютер») — отдельная задача.

## Плитки (разделы)

Обо мне · Опыт работы · Навыки · Образование · Проекты · Контакты · Резюме (PDF)

## Подходы (рассмотрены)

- **A — страницы внутри окна (выбран).** Как настоящая Панель управления, рабочий стол не
  захламляется, навигация «Назад» ощущается как XP.
- B — каждая плитка открывает отдельное окно. Проще, но плодит окна; отклонён.

## Как устроено

- `Open_Windows/About Me/About Me.html` + `About Me.css` — разметка и стили, по схеме остальных
  окон (их подгружает `openWindow` из `Bureau/Bureau.js`).
- Контент — в одном JS-объекте (`Open_Windows/About Me/about-me-data.js`), чтобы владелец правил
  текст в одном месте, не трогая разметку. Пока владелец не прислал данные — **заглушки**,
  явно помеченные «заполните».
- Логика навигации — `Open_Windows/About Me/about-me.js`, подключается в `Bureau.html`;
  `openWindow` после вставки содержимого вызывает `initAboutMe(windowElement)` (скрипты внутри
  `innerHTML` не исполняются).
- Иконки — из пакета XP в проекте (User Accounts, Briefcase, Certificate, Programs, Address Book,
  Email, Generic Document и т.п.); иконка окна/ярлыка — User Accounts под именем `About Me.png`.
- Плитка «Резюме (PDF)» открывает `Assets/Docs/resume.pdf` в новой вкладке; пока файла нет —
  XP-сообщение «Файл пока не добавлен».
- Название в заголовке и панели задач — «Обо мне» (через `appDisplayNames`).

## Решения на усмотрение исполнителя

- Точные отступы/градиенты боковой панели — по макету, но переиспользуя классы
  `content_left_card*` из «Мой компьютер», где они совпадают.
- Проверка — headless-браузер (Chrome через puppeteer-core) из временной папки: открыть окно,
  пройти по всем плиткам, «Назад»/«Вперёд», сравнить со скриншотом макета.
