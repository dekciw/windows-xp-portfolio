# Все проекты в «Моих проектах» - дизайн

**Дата:** 2026-11-15 · **Размер:** проект (в основном контент и медиа, кода мало)

## Зачем
В окне «Мои проекты» одна полностью доведённая карточка - Burger Cheddar (обложка, видео-превью при наведении, страница проекта с плеером-каруселью, описанием и комментариями; см. `2026-11-14-project-card-video-preview-design.md` и `2026-11-15-project-page-design.md`). Пользователь хочет такие же карточки для всех своих проектов. Сайт - развлекательное портфолио в стиле Windows XP.

## Цели
1. 13 карточек (Burger Cheddar + 12 новых), каждая с обложкой, видео-превью при наведении и страницей проекта того же вида, что у Burger Cheddar.
2. Проекты: 2rism, ExploreNorway, DynamicIslandCSS, PizzaChef, MacaroonsShop, TrendyCookies, CoffeSun, StrongClubBarbershop, FashionStore, SuperCars, PrometConfigurator, KabanesBot (+ Burger Cheddar). Не входят: WeatherCard, windows-xp-portfolio, dekciw, github-activity.
3. На каждой странице: слайд 1 - видео-презентация со звуком, затем 3-4 скриншота; «Открыть сайт» - GitHub Pages проекта; Задача / Роль / Описание; 3-5 комментариев.
4. Все видео-презентации (включая Burger Cheddar, сейчас 22 МБ) пережаты до 720p.
5. **Случайный порядок карточек** (просьба пользователя): карточки перемешиваются при открытии окна и при нажатии «дома» - кнопки «Домой» на панели, логотипа и значка «Все» в боковом меню. Не перемешиваются (решение исполнителя - чтобы карточки не прыгали и после «Назад» было видно, откуда пришёл): переключение раздела, поиск, «Назад»/«Вперёд», возврат со страницы проекта. Раздел показывает свои карточки в текущем перемешанном порядке. Порядок из данных остаётся исходным для перемешивания.

## Не-цели
Изменения в разметке, стилях и поведении карточки и страницы проекта (они доведены); единственная правка кода - случайный порядок (цель 5). Новые поля данных, если без них можно обойтись. WeatherCard.

## Анти-цели
- Поломка Burger Cheddar, поиска, категорий, темы, истории «Назад/Вперёд».
- Тяжёлая загрузка: при открытии окна грузятся только обложки; превью - при наведении; презентация - только на странице проекта, `preload="metadata"`.
- Отзывы-рекомендации от «заказчиков» или «работодателей». Комментарии - только реплики зрителей о том, что видно на сайте.
- Длинное тире в текстах: только короткий дефис « - ».

## Подходы
1. **Записи в `my-projects-data.js` + медиа в `Assets/Projects` (выбран).** Код уже рассчитан на много проектов: всё, что видит посетитель, берётся из данных.
2. Отдельный JSON на проект с подгрузкой - лишний код и запросы ради 14 записей.
3. Сборка данных скриптом из `presentations/videos.json` - тексты и отзывы всё равно пишутся руками, выигрыша нет.

Видео (решение пользователя): пережать до 720p (H.264 1280×720, AAC, цель 3-5 МБ на ролик) локальным ffmpeg из npm-пакета (`ffmpeg-static`, dev-зависимость, без прав администратора). Отвергнуто: оригиналы 1080p (+145 МБ в репозиторий), YouTube (теряется свой плеер).
