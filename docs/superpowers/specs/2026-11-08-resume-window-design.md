# Окно «Моё резюме» — дизайн

Дата: 2026-11-08 · Статус: согласован · Размер: небольшое изменение

## Зачем

Посетитель портфолио должен открыть резюме прямо на рабочем столе и спокойно его прочитать,
не уходя на другую вкладку. Сейчас пункт «Резюме» в «Пуске» — заглушка «Скоро», а кнопка
«Моё резюме» в «Обо мне» ведёт на несуществующий `/Assets/Docs/resume.pdf`.

Текущий PDF (выгрузка с hh.ru) — заготовка: владелец заменит его на точную версию позже,
тогда же уберёт телефон, дату рождения и метро. Поэтому замена PDF должна быть одной командой.

- Иконка «Моё резюме» на рабочем столе (`pdf-icon.svg`), открывается двойным щелчком, как остальные.
- Страницы резюме — белые листы с тенью на сером фоне, листаются вертикально.
- Щелчок по странице — увеличение; в увеличенном виде страницу можно таскать мышью; повторный
  щелчок без перетаскивания — обратно «по ширине».
- «Масштаб» — переключает «по ширине окна» / «крупно» (то же, что щелчок).
- «Сохранить» — скачивает настоящий PDF (`Assets/Docs/resume.pdf`, атрибут `download`).
- «Печать» (кнопка и пункт меню «Файл») — печатает сам PDF: он грузится в скрытую рамку и открывается диалог печати браузера; если браузер так не умеет, PDF открывается в новой вкладке. «Справка» в меню — неактивна. (Добавлено по просьбе владельца после первой версии.)
- «Связаться со мной» — открывает Telegram `https://t.me/atanov_roman` в новой вкладке.
- Меню «Файл»: «Сохранить», «Закрыть». «Вид»: «По ширине», «Крупно».
- Пункт «Резюме» в «Пуске» и кнопка «Моё резюме» в «Обо мне» открывают это окно.

## Подходы

1. **Картинки страниц из PDF + PDF для скачивания (выбран).** Выглядит одинаково во всех
   браузерах и на телефонах, легко сделать XP-масштаб. Минус — текст в окне не выделяется;
   закрывается кнопкой «Сохранить».
2. PDF прямо в окне (`<iframe>`/`<embed>`). Чужая серая панель Chrome внутри XP-окна,
   на iOS видна только первая страница, Android Chrome не показывает вовсе. Отклонён.
3. pdf.js в окне. Тот же результат, что (1), но тянет ~1 МБ библиотеки в каждую загрузку. Отклонён.

## Как устроено

- Исходник: `Assets/Docs/resume.pdf`.
- Скрипт `npm run resume` (`scripts/build-resume.mjs`): через puppeteer-core и локальный Chrome
  (как в тестах) рендерит каждую страницу PDF в картинку с двойным разрешением в
  `Assets/Images/Resume/page-N.webp`, обрезает пустой низ последней страницы и пишет
  `Assets/Images/Resume/pages.json` (`[{src, width, height}]`). Окно читает `pages.json`,
  поэтому число страниц не зашито в код. Замена резюме = положить новый PDF и запустить скрипт.
  Для рендера — dev-зависимость `pdfjs-dist` (только в скрипте, на сайт не попадает).
- Окно `Open_Windows/Resume/` по схеме остальных окон; иконка рабочего стола и запуск —
  через существующий `openWindow` в `Bureau.js`.
- Тексты UI на русском, без длинных тире.
- Тесты в `tests/resume.test.mjs` (puppeteer, как остальные): иконка открывает окно; страниц
  столько, сколько в `pages.json`; щелчок увеличивает; «Сохранить» — ссылка с `download` на
  PDF; «Связаться» — Telegram; «Пуск → Резюме» и «Обо мне → Моё резюме» открывают окно.
  Тест «Резюме пока неактивно» в `start-menu.test.mjs` переписывается.

## Не цели

- Скрытие личных данных в текущем PDF (сделает владелец при замене).
- Выделение и поиск текста внутри окна.

## Решения исполнителя (мои, можно поправить)

- Формат картинок — WebP, ширина рендера 2× от ширины страницы.
- Telegram как адрес «Связаться», пункты меню «Файл»/«Вид» — как выше.
